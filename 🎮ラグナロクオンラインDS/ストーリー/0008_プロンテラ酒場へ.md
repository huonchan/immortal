# プロンテラ酒場に進入
- アレス
酒場に着いたけど……。

ルシフィ、お前の知り合いってのは  
どこにいるんだ？

- ルシフィ
ああ、えーっとだな……。

いたいた、あいつだ！

よう、アルド。久しぶりだな。

- アルド
ん〜、なんですかいきなり……。

って、ルシフィさんじゃないか！  
久しぶりですね！

後ろのかたがたは、お知り合いですか？

- ルシフィ
ああ、俺の仲間だ。

- アルド
そうなんですか、初めまして、  
私はアルドといいます。

- アレス
ん、ああ、アレスだ。

んで、こっちはシェラ。

よろしくな。

- アルド
ええ、こちらこそ。

それで、今日はどうしたんですか？

- ルシフィ
ああ、実は俺達は  
"エンペリウム"を探しているんだが……。

お前がちょっと前に言ってただろ？  
ありかを知っているって……。

- アルド
なるほど……。
"エンペリウム"ですか。

確かに"エンペリウム"がある場所を  
私は知っていますが……。

- ルシフィ
だったら頼む！  
教えてくれないか？

- アルド
いくらルシフィさんの頼みでも、

タダで教えるというわけには  
いきません。

一つ条件があります。

- ルシフィ
条件？

- アルド
ええ、私は今ほしいものがあるんですよ。  
それを探してきてもらうのが条件です。

- アレス
ほしいもの？

- アルド
はい。

"フリオニのナミダ"というアイテムです。

これを持ってきてくれたら"エンペリウム"  
のありかを教えましょう。

- ルシフィ
"フリオニのナミダ"か……。

どこにあるんだそれは？

- アルド
それがわかれはま、自分で  
取りに行っています。

- アレス
じゃあ、  
どうやって探せって言うんだよ……。

- アルド
それは、自分達で考えてください。  
これを見つけられないようじゃあ……

"エンペリウム"なんて夢のまた夢ですよ。

- ルシフィ
どうする？　アレス？

- アレス
（ギルドを作って、  
　オレは強くなって見せるんだ！）

- アレス
……わかったよ、探してくる。

- アルド
……わかりました。見つけたら  
私のところまで持ってきてください。

- アルド
私はここにいますので。

- アレス
ああ。

- アルド
あなたに女神フレイヤ様のご加護が  
あらんことを……。

- アレス
ん？　フレイヤ？？

- アルド
おっと、失礼しました。

- ルシフィ
ハハハ、珍しいだろ？  
アルドは王国出身なんだが、

女神フレイヤをあがめているんだ。

- アルド
ここルーンミッドガッツ王国では  
オーディンを主神としてますから。

アルナベルツ教の言葉を聴くと  
気分を害される方もいるようなので

発言には気をつけてはいるのですが……。

- アレス
ふーん、まあオレは別に気にならないぜ。

正直な話、信仰に関しては  
よくわかんねーしな。

- アルド
そう言ってもらえると助かります。

と言っても私もそこまで信仰深くは  
ないのですが……。

- ルシフィ
なんだ？　そうなのか？

- アルド
ええ。私の大切な人が女神フレイヤ様を  
信仰していたからっていうのが

私の信仰理由ですから。

- ルシフィ
していたってことは……。

- アルド
……もう過去の話ってことですよ。

外へ

- アレス
"フリオニのナミダ"か……。

見つけてくる、とは言ったものの……  
まったく手がかりのないアイテムを、

どうやって探せばいいんだ？

- ルシフィ
"フリオニ"っていうのは  
モンスターの名前のようだけど……。

依頼を受けながら情報を集めて  
探すしかないんじゃないか？

もしかしたらその依頼で  
見つかるかもしれないしな。

- アレス
そんなのんびりしてられないだろ！

- ルシフィ
……アレス、  
何をあせってるんだ？

- アレス
別にあせってなんかねえよ。

- ルシフィ
ならいいんだが……。

……とにかく、急がば回れって言うしな。  
モンスター討伐の依頼を受けようぜ。

- アレス
（モンスター討伐か……  
　強くなるにはちょうどいいかもな）

……なにかあるのか？

- ルシフィ
ああ、地下水路でモンスターが  
大量発生しているって話があっただろ？

- アレス
ああ、前にオレ達が  
入隊試験を受けたやつだろ？

- ルシフィ
討伐の準備が、そろそろ  
終わるころだと思う。

手始めに受けてみないか？

- アレス
……よし、じゃあ騎士団に行くぞ！

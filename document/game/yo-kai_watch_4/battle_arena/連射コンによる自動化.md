# 目的
- レベル上げ
- 魂集め
- クセモノ妖怪探し
の、自動化

# いる物
## 連射コントローラー
XとAを連射できるもの。あまり早く連打する必要はないため、変速機能があるなら遅くしたほうが暴走防止できるかも
## ゴム
ZRとZLを押しっぱなしにする。弁当のフタとか止めるゴムだと切れる事があるため、試しにやって動作安定が保証されたらヘアゴムや100均一にある衣類用替えゴム等、強度があるものにしたい。
## いい感じの暇つぶし
読書とか、家事とか、軽い散歩（挙動の安定保証は無いので20分以上の離席はオススメしない）とか

# 手順
- 連戦したいドクロの正面で会話が出来る"ギリギリ"の距離に立つ
- ここでAの自動連打実行
- 会話発生したらYの自動連打実行
- ZRとZLをゴムで固定
- 魂スイトールと連戦が自動化されてるか1回目視で確認
- 出来ていたら後は寝るなり散歩なりお好きに

# 各ボタン役割
- A:会話自動、ピン刺し、オートいいじゃん
- Y:通常攻撃連打
- ZR:オート魂スイトール
- ZL:オートピン刺し

# 不具合
> 対策考え中
- Xも連打させると技もオートで撃てるが、戦闘終了後にメニュー展開によるループ崩壊のリスクが高まる
- 戦闘終了後になぜかじわじわカメラがずれて会話が途切れる
- 稀に会話よりマップ展開が先に走ってループが壊れる

# パーティー構成
## フミ（ウォッチャー）
トウマは鬼の手や変身と魂スイトール自動化の相性が最悪なので不採用。採用ヒーラーの性能によっては攻撃的なウォッチャー採用もあり。必殺技はミンナヘンゲ一択。回復とグレード化での強制バフ狙い
### 技構成
- ミンナヘンゲ【癒】
- みんなヒーリング
- YP与えるアレ
- やすらぎ地蔵

## 1番目（スターター設定）
- メイン攻撃役
- 通常攻撃が早く、魂スイトールのために、大きく前に出れる妖怪が望ましい
### オススメ妖怪
- 山姥

## 2番目（予備火力）
- 1番目がなんらかの事故でデスしたときの代役
- 1番目がデスしてる時点で緊急事態なので、純粋に試合終わらせる力高いパワー系でいい
### オススメ妖怪
- 紫炎
	- 弱点が無いため、妖術による即死の心配が少ない
	- 通常攻撃に物理まもりダウンがあり相性がいい

## 3番目（ククリ姫）
- こんすい確率上昇
- フミ以外のサブ回復
- 必殺技てま1番目のデスを回復する切り札
- 火力は期待しないので、武器はアイテムドロップ率あがるナラクとかでいい
### 代用
- 月神ツクヨミ
	- 純粋な回復役では無いので稀に不安定
	- PTの生存力は高まるが、こんすい確率が犠牲になる
- コンたん
	- ククリ姫の下位互換
	- 回復頻度と蘇生力と生存力が不穏

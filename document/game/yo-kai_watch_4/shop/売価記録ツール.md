# 売価
売価が-1は売却不可。-2は未調査
## 食料品
| 名前 | 売価	|
| ---- | ---- | 
while（食料品配列数）
| ［名前］ | ［売価］	|
end
## 道具
| 名前 | 売価	|
| ---- | ---- | 
while（道具配列数）
| ［名前］ | ［売価］	|
end
## 装備品
| 名前 | 売価	|
| ---- | ---- | 
while（装備品配列数）
| ［名前］ | ［売価］	|
end

> データ設計

- 食料品［］: object［］
	- data［］: object ［］
		- アイテム名:string
		- 売価:int

- 道具［］: object［］
	- data［］: object ［］
		- アイテム名:string
		- 売価:int

- 装備品［］: object［］
	- data［］: object ［］
		- アイテム名:string
		- 売価:int

> html設計

- 食料品、道具、装備品それぞれに「名前、値段」を書いて+ボタンで追加できるようにする
	- アイテム名が重複してた場合、ダイアログを出して拒否する。
- 追加したアイテム名や値段は変更可能。項目位置も上下ボタンで入れ替えれるようにする
- mdファイルをセーブデータ代わりにし、インポート、エクスポートできるようにする
- ファイルインポート時および編集中はローカルストレージにファイル名の名前でデータを仮保存。エクスポート時にローカルストレージのデータを消去。
